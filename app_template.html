Melvor Idle 2 시뮬레이터

대기 중
레벨
세이브의 경험치로 계산된 값이 기본입니다. 값을 바꿔 "레벨이 오르면 어디가 좋아질지"를 볼 수 있습니다.
장비
칸을 클릭해 아이템을 고릅니다. 수치는 현재 스탠스 기준 명중 / 힘 / 평균 방어 / Protection이고, 노란 테두리는 세이브와 달라진 칸입니다.
전투 방식
장비 외 광원(암흑 지역용)
음식 · 자동식사
% 이하가 되면 먹음
%
모델 설명
게임 DLL을 디컴파일해 대조한 공식을 그대로 사용합니다.
• 명중/회피 = floor((레벨+9)×(보너스+64)), 명중률 = 1−회피/(2×명중) 또는 명중/(2×회피)
• 최대타(근접/원거리) = floor(22+레벨+(레벨+17)×힘/64), 마법 = floor(주문최대타×(1+피해보너스)×(1+(레벨+1)/200))
• 저항 = Protection/(상대 Power+Protection) 최대 70%, 삼각형 ±15%; 피해 순서 저항 → Ward → Armour → 최소 1
• 자동식사: HP ≤ round(최대HP×임계)이면 floor((최대HP−HP)/회복량) 개를 먹음 (최소 1). HP 자연회복 없음
• XP = 준 체력 피해×스탠스 배율 + 처치 시 배율×(4×Armour+50×Ward). 스폰 대기 3초
• 미반영: 기도, 물약, 장비 고유 보너스, TurnCounting 계열 적 패시브. 사망 시에도 시뮬레이션은 계속되며 사망/시간으로 표시
설정이 바뀌었습니다. 아래 결과는 이전 설정 기준입니다.
왼쪽에서 장비·스탠스·음식을 설정하고
▶ 시뮬레이션 실행을 누르세요.
모든 적과 던전을 대상당 선택한 시간만큼 반복 사냥했을 때의 XP/시간과 음식 소모를 비교합니다.
스킬 레벨
레벨은 해금 여부와 요리 성공률·도둑질 은신에 영향을 줍니다. 전투 스킬 요구치는 전투 탭의 레벨을 따릅니다.
보너스 툴벨트 · 펫 · 길드 · 상점
세이브에서 읽은 툴벨트 장착품·상점 구매·펫이 기본값입니다(✓ 보유). 바꿔 보면 결과가 즉시 다시 계산됩니다.
재료 수급 경로 SimcoTools 방식
모델 설명
디컴파일한 각 스킬 ActionStats/ActionComponent 의 공식을 기대값으로 계산합니다.
• 창고 가치 = 아이템 판매가(SellsFor) 합 + GP. 재료를 창고에서 쓰면 그 판매가만큼 가치가 줄어든 것으로 계산
• 수급 경로: 창고(판매가 차감) / 상점 구매(GP 가격 차감) / 직접 생산(비용 0, 생산 시간을 더해 시간당 가치로 환산, 부산물 포함)
• 보너스 합산: 같은 스탯의 값을 모두 더함(상점은 구매 수량 배). 적용 범위(스킬/카테고리/레시피/아이템)는 게임 데이터의 LocalContext 그대로
• 벌목: 나무 체력 ceil((기본+고정)×(1+%)), 타격당 1 피해(약점 3+10%체력, 2배 피해, 즉시 벌목), 벌목 완료 시 산출×(1+2배확률)
• 채광: 타격당 성공 확률 = 기본×(1+%), 누적 진행도 ≥ 1이면 확정. 분쇄 ×3 수량·×2 XP
• 낚시: 간격 균등분포 평균, 물고기 확률 아니면 쓰레기(재굴림 적용), 가중치 산출, 특수 아이템 누적 확률
• 요리: 성공률 = (69+숙련)/(69+난이도), 숙련 = 레벨+보너스. 제작(제련·공예·화살·룬·야수): 단계 수와 건너뛰기 확률로 기대 행동 수
• 약초학: 준비+가열+교반 후 병입 10회(병입마다 재료 소모·물약 3개). 도둑질: 성공률 = (100+은신)/(100+감지), 실패 시 기절·피해
• 농사·제분소·목축은 다른 활동과 동시에 진행되는 수동 활동이라 구획 1개 / 동물 1마리 기준입니다. 동물 구매비는 수명으로 나눠 반영하고, 구획·땅·축사 구매비와 자동화 비용은 미반영입니다. • 미반영: 소모성 툴벨트(물약) 소모 비용, 낚시 미끼, 점성술 노드, 사냥/민첩, 상점 판매가 수정자, 희귀 드롭의 실제 분산
